# ControlQuest: calibration and comparison runs (raw output)

Recorded 2026-11-19 for docs/RESEARCH.md (final validation, engine 0.14.0). Everything below was
printed by the existing game/engine_server/calibrate.py (commands start with "$"), run inside the
course Docker image (`<image>` = vsc-mpcrl26-exercises-*), from game/engine_server:

    docker run --rm -v "<repo>:/workspace" -w /workspace/game/engine_server <image> python calibrate.py <args>

Code: branch `gui`, commit a7ab364 plus the uncommitted reduced-scope changes (Heavy Ball
removed, wording fixes, research debrief, final validation; engine 0.14.0). Host: Intel Core
i7-13700HX, Windows 11 Home, Docker Desktop (engine 29.4.0). Software in the image: see the
section "environment" below.

Notes: "t" is the time to the target for a success and the time until the run stopped for
every other outcome. "E" is the effort measure sum(dt*|u|^2), not physical energy. "mean solve"
is acados' own solver time per OCP (time_tot), without simulation and Python overhead; it
depends on the machine and varies between runs. Each calibrate.py call is a new process that
first builds its solvers (a few seconds; Dead End prints it); the solve times do not include that.
"left" is the distance to the target when the run stopped. Crosswind: "max_drift" is the largest
distance between the ball and the prediction of the plan in force (up to and including the
moment that plan is replaced), "mean_replan_deviation" its mean at the re-planning instants
(engine 0.14.0; the definition before 0.14.0 missed the end of every open-loop stretch, see
verify_numerics_2026-11-19.txt).
